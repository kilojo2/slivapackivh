# SlivaPack

Платформа публикации фото и видео. Контент публикуется только через Telegram-бота; веб-админки нет.

> ⚠️ **Согласие.** Публикация допускается только с подтверждённого согласия изображённых людей. См. раздел «Согласие и удаление контента».

## Структура

- `apps/web` — фронтенд (Next.js): лента карточек, просмотр, лайки.
- `apps/api` — бэкенд (NestJS): REST API + webhook Telegram-бота.
- `packages/shared` — общие типы и константы.

## Безопасность

- Все секреты — только через переменные окружения (`.env`), в git не попадают (см. `.env.example`).
- Скан секретов (gitleaks) и аудит зависимостей (`npm audit`) — в CI.
- Валидация ввода, rate limiting, безопасные HTTP-заголовки, CSP.
- Медиа: проверка по magic bytes, удаление EXIF/GPS, приватное S3-хранилище, отдача через CDN/подписанные URL.
- Публикация — только через allowlist пользователей Telegram.

## Локальный запуск

```bash
npm install
cp .env.example .env   # заполнить реальными значениями
npm run build
```

## Согласие и удаление контента

Контент публикуется только с согласия. Для запроса на удаление — контакт **@heroinstead** (см. раздел «Контакты»).
